Set up your local worker.

CAPTIFY renders clips on this Windows PC. Add a Groq API key for speech transcription. Gemini keys are optional.

Create or manage keys at console.groq.com/keys.
Keys are encrypted using Windows credential encryption and stored on this PC. They are passed to the local worker and are not committed to GitHub. The original video stays on this PC; only extracted speech audio is sent to Groq for transcription. AI transcription needs internet access and may be subject to provider quotas and pricing.
