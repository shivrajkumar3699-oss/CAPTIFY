CAPTIFY - BACKGROUND MUSIC FOLDER
===================================

Yahan par tumhe kuch royalty-free MP3 files manually daalni hain.
Ye files edited clips mein background music ke roop mein use hongi
(jab user "Add BGM" option ON karega).

KAHAN SE LENA HAI (dono free hain, no login/card zaroori nahi hai
downloading ke liye, sirf attribution rules follow karna in dono ke):

1. YouTube Audio Library
   https://studio.youtube.com/ -> left sidebar -> Audio Library
   (Google account se login karna padega, lekin card nahi lagta)

2. Pixabay Music
   https://pixabay.com/music/
   (Bina login ke bhi download ho jata hai)

KYA DOWNLOAD KARNA HAI:
- 5-10 chhoti MP3 files (upbeat/chill background type music,
  jo bina lyrics ke ho to best hai - vocals captions ke saath clash
  kar sakte hain)
- File size chhota rakhna (har file ~3-5 MB se zyada na ho)

FILES YAHAN ISI FOLDER MEIN DAAL DO:
C:\projects\captify\worker\assets\bgm\

Bas .mp3 extension honi chahiye, naam kuch bhi rakh sakte ho.
Code automatically in sabme se random pick karke use karega.
